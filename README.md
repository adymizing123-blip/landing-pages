## Publish with GitHub Pages

1. Create a new **public** repository and upload everything in this folder (keep the folder structure, including the hidden `.nojekyll` file).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`, and each page at `https://YOUR-USERNAME.github.io/REPO-NAME/cardiologist/` and so on.
